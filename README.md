# 📚 Schoolkit

Schoolkit is a simple web-based school management system built using **PHP and CSS**.  
It allows users to manage school records with features such as adding, editing, deleting, and viewing data.

This project is created for learning and academic purposes.

---

## 🚀 Features

- ✅ User Login System
- ✅ Add Records  
- ✅ Edit Records  
- ✅ Delete Records  
- ✅ View Details  
- ✅ Simple and Clean UI  
- ✅ Database Connection (MySQL)

---

## 🛠️ Technologies Used

- **PHP**
- **CSS**
- **MySQL**
- **XAMPP**
- **HTML**
